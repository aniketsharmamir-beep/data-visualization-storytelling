# Data Visualization and Storytelling: Who Survived the Titanic?

## Objective
Tell a story with data: use charts to show who survived the Titanic and why.

## Story in Brief
1. Only 38% of passengers survived
2. Women survived far more often than men
3. Higher ticket classes had better odds
4. Sex and class together explain most of the gap
5. Children had the best odds by age

## Files
- notebooks/titanic_story.ipynb: code for all six charts
- images/: the charts as PNG files
- presentation/titanic_story.pptx: slides summarizing the findings
